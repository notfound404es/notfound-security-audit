# Security policy

If you find a vulnerability in NotFound Security Audit itself (for example, a way to make the scanner leak a
secret into a report, write into the scanned project or execute project code), please report it privately
through GitHub's **Report a vulnerability** button on this repository, or by email to contacto@notfound404.es.
Please do not open a public issue for it.

False positives, missed patterns and outdated advisories are not security issues: open a regular issue.
